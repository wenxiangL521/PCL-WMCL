# 人工配置

启动器尽量自动完成安装/Java/下载；以下需要你本人提供账号、Key 或系统权限。**所有密钥都不要提交到 Git、截图或日志。**

## 1. CurseForge API Key（可选）

仅 CurseForge 搜索/下载需要；Modrinth、原版安装和启动不需要。

1. 打开 <https://console.curseforge.com/> → **API Keys** → 创建 Key。
2. 启动器 **设置 → 其他 → CurseForge Key** 粘贴并点“测试”。
3. 或启动时使用环境变量：

```bash
WMCL_CURSEFORGE_API_KEY='你的key' dotnet run --project src/WMCL.App -c Release
```

Key 是账号凭据，不要写入仓库或公开 issue。

## 2. 微软正版登录 Client ID（可选）

离线账户/Authlib 不需要。微软登录使用**设备码 + 公共客户端**，不保存 Client Secret。

1. 打开 <https://entra.microsoft.com/> → **应用注册** → **新注册**。
2. 账户类型选 **任何组织目录中的账户和个人 Microsoft 账户**。
3. 复制 **应用程序(客户端) ID**。
4. **身份验证 → 高级设置 → 允许公共客户端流** 设为 **是**。
5. 不需要创建客户端密码。
6. 启动器 **设置 → 其他 → 微软 Client ID** 填入并保存。
7. 启动页选“正版”，设备码生成后自动复制到剪贴板，再打开微软官方验证页；在网页中粘贴代码完成授权。每次登录会话只自动执行一次，返回或取消后不再自动打开网页。
8. 剪贴板或浏览器不可用时，登录页会单独提示，并保留“复制设备码”“打开登录页”及可选择的代码作为备用；过期/失败后可重新获取设备码。只允许微软固定 HTTPS 验证地址，不接受任意网页或本地协议。
9. 登录后左栏只保留“皮肤与披风”入口；修改、刷新、保存皮肤，以及披风和兑换操作集中在该窗口。窗口右侧可滚动、按钮自动换行，第三方皮肤衣柜仍使用原网页入口。
10. 修改皮肤：点击“修改皮肤”选择64×64或64×32 PNG，或在展开区输入本地路径；先看完整模型并选择classic/slim，再点“上传并应用”。本地预览/像素编辑本身不改变账号；过期登录须重新登录后提交。系统选择器不可用会提示，可改用路径输入。
11. 预览可拖动旋转，也可用正面/背面按钮或左右键；选择披风即预览，只有点击“应用披风”才提交。披风纹理加载失败不代表账号披风被删除。

> 新应用默认不能调用 Minecraft 服务，`login_with_xbox` 会返回 `403 Invalid app registration`。
> 需要按 <https://help.minecraft.net/hc/en-us/articles/16254801392141> 申请 Minecraft 白名单；
> 审批通过后同一个 Client ID 生效，代码不用改。本项目不提供 Client ID。

## 3. EasyTier（默认联机方案，可选）

- 需要能访问公共中继；可“获取公共节点”或“自动选择中继”。
- Linux 需要 `/dev/net/tun` 与 `CAP_NET_ADMIN`：

```bash
sudo modprobe tun
ls -l /dev/net/tun
sudo setcap cap_net_admin+ep ~/.cache/WMCL/easytier/<版本>/easytier-core
```

失败时启动器会提示，并可切换到陶瓦。

## 4. 陶瓦 / Terracotta（备用）

1. 联机页切换为 **陶瓦（HMCL）**。
2. 房主创建房间 → 启动陶瓦 → 在 Minecraft 中对局域网开放 → 把 `U/...` 房间码发给朋友。
3. 客人加入房间 → 启动陶瓦 → 多人游戏直连界面显示的 `127.0.0.1:端口`。
4. 停止时点“停止”。

Terracotta 由 burningtnt 开发，AGPL-3.0：<https://github.com/burningtnt/Terracotta>。本项目通过本地 HTTP API 调用未修改的二进制；可用 `WMCL_TERRACOTTA_PATH` 指定本地文件。

## 5. Nide / 第三方认证

启动页“第三方” → 填 Nide 服务器 ID 或完整 Authlib/Yggdrasil 地址 → 登录。实例设置可固定认证服务器。

## 6. Java

设置页可安装 Java 8/17/21，或手动指定路径；已有系统 Java 会优先复用。下载失败通常是网络/镜像问题。

## 7. 更新源（可选）

准备 `latest.json` 后，在 **设置 → 其他 → 更新源** 填 URL，在关于页检查/下载。Linux 运行中的单文件替换需要辅助脚本/AppImage；Windows/macOS 自动更新尚未实机验证。

## 8. 配置导入与恢复

- 外部 JSON/文件导入不会启用启动前命令、启动前等待设置、Java 路径、额外 JVM/游戏参数、自定义 XAML 主页、陶瓦程序路径或更新源。这些字段可能执行代码或引入可执行内容，必须在本机检查后手动填写；导入到现有设置时保留本地已配置值。普通主题、内存等设置仍可迁移。本机启动时读取的可信配置不受此限制。
- 配置使用同目录临时文件写入并刷新后原子替换；成功保存前保留上一份有效配置为 `.bak`。主配置损坏或缺失时尝试备份，并在启动时显示恢复提示；两者都不可用则明确提示暂用默认值，不在读取时覆盖原文件。
- 下次保存会先将损坏主配置保留为 `.corrupt-<随机标识>`，再提交新配置。备份和损坏副本可能含代理密码等敏感信息，不要分享或提交到仓库；确认恢复后可自行清理。

## 9. 导入导出与下载边界

- ZIP/mrpack/mcbbs 导出明确拒绝源目录及其祖先、文件或选项中的符号链接/重解析点（即使链接指向实例内部）；请先将需要分享的内容复制为普通文件。失败会清理临时归档，已存在的输出不覆盖。
- WMCL 实例 ZIP 导入会迁移新实例 ID、profile 与安装清单，并为已导出且哈希相符的受管文件保留本机修复归档。不会使用导出方的绝对原始归档路径；未导出的共享库、资源不纳入新清单，禁用资源补全时不保证可直接启动。用户修改文件不被错误登记为旧哈希的修复源，已有存档修复时继续保留。
- 安装时若 `assets/indexes/34.json` 等同 ID 索引出现不同内容，可能是官方不同快照/版本的合法修订，不代表存档或 Mod 损坏。新建/修改实例会为已验证的新索引使用 `34-<完整SHA1>.json` 并只调整当前实例引用，旧索引与旧实例保持不变；无需手动删除旧文件。未验证索引、legacy 虚拟/resources 映射或普通库冲突仍会拒绝覆盖，避免误伤其他实例。
- 下载提交前验证已知文件长度；断点响应的范围与正文长度必须一致。有 SHA1 的文件可在最终哈希验证下续传；无 SHA1 的旧 `.part` 无法证明属于同一版本，因此恢复、重试或切换镜像时完整重下，不再盲目拼接。
- GUI/CLI 每次真正启动游戏前自动校验客户端、当前平台依赖库、native 归档、资源索引/资源对象与日志配置；完整文件仅本地核验，不要求强制联网，缺失或损坏才联网补全。校验或补全失败、取消时均不启动游戏；GUI 会显示可重试提示，并在任务管理中显示独立阶段。
- 校验不修改整合包 profile、Mod、配置和存档；本地 profile/继承链缺失或无可用下载来源时会提示重新安装/恢复，而不是猜测版本。没有哈希等完整性元数据的本地自定义文件只能确认存在，不能保证密码学完整性。旧版 virtual/resources 映射会从已验证对象补齐。
- 导出路径检查是逐段托管属性校验，不提供操作系统级原子 no-follow 保证；不要让不可信进程在导出期间并发替换目录组件。

## 10. 界面缩放与 Niri 窗口特效

- 设置 → 个性化 → UI 缩放支持80%~150%，按5%调整；鼠标拖动松开后更新整个布局，键盘修改立即生效，包含自有对话框及下拉菜单。原FontScale配置字段兼容保留，不需要重启。
- “窗口透明度”与PCL-ME一致：滑块0~100%映射为窗口不透明度下限~100%，整窗透出模糊桌面；深色主题或有背景图时下限40%，浅色主题且无背景图时下限75%，避免深色文字被明亮桌面洗白。兼容原ApplicationOpacity字段，旧值会按0~100归一。“壁纸不透明度/模糊”仍单独作用于背景图。
- “桌面背景模糊”向支持的窗口后端请求，设置页显示实际透明级别。Niri 下该效果受合成器规则控制：选择开关后点“应用 Niri 规则”，查看目标配置路径并确认；程序先备份、生成只匹配WMCL.App的块，再执行niri validate，成功且原文件未被外部编辑后才原子保存。
- 不会静默改全局模糊强度或其他应用规则，不给Niri添加opacity规则以免与应用不透明度叠乘。取消、验证失败、检测到外部改动时不覆盖原文件；原配置为符号链接时，请用“复制 Niri 规则”手动加入实际配置。旧Niri不支持background-effect时校验会明确失败，不能把请求视为已生效。

## 11. 手动安装 Java

- 设置 → Java 可选择8、11、17、21、25。手动安装精确主版本及当前进程架构；如已有对应兼容运行时会直接复用，不因“更高版本兼容”悄悄换成其他主版本。
- 使用Temurin对应平台发布，下载前读元数据，下载后校验长度和SHA256，解压后探测主版本及架构才提交。Adoptium API不可达可尝试同发行商GitHub发布源；厂商没有提供构建的平台会明确提示，需手动安装，不会把ARM64当x86或装错版本。
- “清理下载的 Java”只针对启动器管理的下载目录，不删除系统或手动安装的JDK。此次回归没有执行真实Java下载安装；已核对11/25的发布元数据，实际网络仍可能受代理、TLS或GitHub访问限制影响。

## 12. 账号与密钥边界

- 微软/CurseForge 账号与密钥必须由你本人提供。
- 真实 Azure Client ID、CurseForge Key 的联网验证需要在你的网络/账号下完成。
- PCL2 官方 EasyTier 房间服务、遥测/赞助/秘钥不在开源重写范围内。
