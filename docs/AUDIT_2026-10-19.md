## 本轮发现并修复

### S1（已修）组合安装按阶段权重汇总进度

`InstallStage` 增加权重（原版 4、加载器 6、OptiFine Mod 2、其余 1），组合安装总进度改为阶段加权，而不是直接取当前任务百分比。TaskManager 仍按顶层任务权重汇总。

剩余：没有 PCL2 每个加载器内部的更细权重树。

### S1（已修）崩溃报告结构化摘要

`CrashAnalyzer.AnalyzeGameDirectory` 现在会：
- 读取 `crash-reports` 最新 `.txt`；
- 解析 `Description:` 生成“崩溃报告摘要”；
- 返回 `CrashReportPath`；
- 启动页新增“崩溃报告”打开按钮；
- 诊断包附带 `crash-report.txt`。
新增测试覆盖 crash-report 解析与诊断包条目。

### S1（已修）整合包 overrides 修复

安装清单现在记录原始整合包路径、overrides 前缀/根目录。实例页“修复基础文件”会在基础/Mod 修复后：
- 从原始 zip 重新解压 overrides；
- 覆盖缺失/损坏文件；
- 原始包不存在时跳过并提示。
新增 `OverridesRepairTests`。

### S1（已修）CurseForge 可选文件逐项选择

原实现只有 `includeOptional` 全选/全不选；现在：
- `GetOptionalFilesAsync` 读取 manifest 的 `required=false` 文件并查询显示名；
- ModpackViewModel 逐个确认；
- `InstallFromFileAsync` 接受 `selectedOptionalFileIds`，只下载选中的 optional 文件；
- 新增列表查询测试。

通过项目 ID 的 fallback 也已统一走“先下载 → 逐文件询问 → 再安装”。

### S1（安全，已修）下载文件名路径穿越

CurseForge/Modrinth 返回的 `FileName` 直接参与 `Path.Combine`，恶意项目文件名（`../x`、绝对路径）可写出目标目录。

修复：
- `FileUtil.SafeFileName()`：只保留单段文件名；
- `FileUtil.SafeChildPath()`：拒绝 `..`、绝对路径、盘符，并校验目标在 root 下；
- 已应用到 CurseForge、Modrinth、Modpack 下载/安装目的地；
- 新增测试 [FileUtilTests.cs](tests/PCL.Core.Tests/FileUtilTests.cs)。
- 进一步覆盖版本 JSON：客户端 `downloads.client.path`、Maven 相对路径、资源索引 id、log 配置、资源 hash、natives 路径统一走安全校验；
- `VersionRepository.GetVersionDirectory` 拒绝 `../`/目录分隔符；
- 新增 [VersionRepositorySafetyTests.cs](tests/PCL.Minecraft.Tests/VersionRepositorySafetyTests.cs)。

剩余：
- OptiFine 官方文件名、zip 内部条目等还未统一走安全函数。

## 仍存在的差距（按优先级）

### P0 / 正确性

1. **安装模型仍是近似**
   - 当前：基础版本 + 单加载器，随后 `MergedInstanceBuilder` 展平；
   - PCL2：`McInstallRequest` 组件选择 → 多组件合并 → 单实例；
   - 影响：LiteLoader、多加载器组合、安装清单 managed files 的完整语义仍不等价。

2. **TUN 不可用**
   - 当前机器 `/dev/net/tun` 存在但 `TUNSETIFF` 返回 ENODEV；
   - EasyTier 已做启动前预检并回退陶瓦；
   - 真实 EasyTier 虚拟 IP 联机未验证。

3. ~~整合包可选文件只能全选/全不选~~：已支持逐文件询问，项目 ID fallback 也已统一。

### P1 / 功能与稳定性

4. **任务树仍不完整**
   - 有任务球/窗口/组合安装阶段树/权重/历史；
   - 没有 PCL2 每加载器内部的完整权重树。

5. ~~崩溃规则 33 条~~：已扩到 **45 条**，新增 JDK/OpenGL/配置/签名/Mod 注册冲突/Java 11/类型转换等；crash-report 结构化/诊断包已接入。仍可继续做堆栈深度分析。

6. ~~整合包 overrides 无法自动修复~~：已通过原始整合包重新解压；依赖原始包仍在缓存/原路径。

7. **皮肤能力**
   - 微软 PNG 上传 + 尺寸校验；
   - Authlib 上传、本地皮肤库、披风显示未实现。

8. **真实外部服务未验证**
   - 微软 Client ID、CurseForge Key 需要用户账号；
   - Uptime 节点 API 在当前网络 DNS 不可达；
   - 这些已整理到 `MANUAL_SETUP.md`。

### P2 / 对齐与体验

9. **插件是客户端目录语义**
   - 已支持 CurseForge Bukkit Plugins / Modrinth plugin；
   - 但没有“服务端实例”模型，默认装到实例 `plugins/`。

10. **世界下载**
    - 支持 CurseForge 世界 zip；
    - 不校验游戏版本、不处理多层嵌套、不做 Modrinth 世界（平台不提供）。

11. **多语言/披风/完整动画**
    - 多语言未做（PCL2 源码也未发现 i18n 资源）；
    - 披风仅接口数据，无 UI；
    - 页面动画为 CrossFade + 浮入，不是 PCL2 每页独立 PageOnEnter。

12. ~~文档漂移~~
    - README/PROGRESS 已更新到 136 tests、当前功能和限制；
    - 旧审计第 0 节已加历史状态说明。
